# 分类

Zhou 等人把深度聚类按表征模块和聚类模块怎样交互分成四支。依据是综述 Figure 1（预印本 arXiv:2206.07579，正式版 ACM Comput. Surv. 57(3)，DOI 10.1145/3689036）：

| 交互 | 在这次实验里的代表 | 含义 |
| --- | --- | --- |
| Multi-stage | AE + K-means，SimCLR + K-means，DINOv2/CLIP + K-means | 先固定表征，再聚类 |
| Iterative | CC；文献中的 DeepCluster | 伪标签或视图一致性来回更新 |
| Generative | VaDE；文献中的 GMM | 显式的潜变量混合 |
| Simultaneously | DEC，IDEC | 表征和簇分配一起受聚类目标驱动 |

这四支不是时间顺序，也不互相排斥。SimCLR + K-means 是多阶段；CC 把对比和簇分配放在同一次训练里，更接近迭代交互。

另一套坐标用来比较方法，不把方法塞进唯一格子：

- 表征空间：原始像素、线性子空间、从零训练的隐空间、外部预训练空间
- 优化：分阶段、交替、联合
- 分配：距离、软分配、混合概率
- 信息从哪来：重构、伪标签、增强视图、外部文本

教材对应关系：第 2 章距离和协方差，第 3 章多元正态和 GMM，第 6 章 K-means 与系统聚类，第 7 章 PCA 作为线性表征，第 8 章因子分析作为潜变量的统计前身。深度编码器替换的是“用什么坐标来度量距离”，不是替换聚类这个任务。
