# 方法选型与两类证据分离

本文件明确区分仓库中的三件事：**实验前的理论假设**、**带标签历史基准的回顾性总结**，以及**无标签训练侧稳定性诊断（E05）及其负面结论**。

## 1. 实验前选型假设（待检验命题，非预设结论）

| 条件 | 实验前优先尝试 | 要验证的假设 |
| --- | --- | --- |
| 维度低、类数已知、计算紧 | K-means 或 PCA + K-means | 非线性表征的 ARI 增益不超过 0.02 |
| 高维、没有外部模型 | AE，然后 K-means | 联合微调不一定更好 |
| 需要嵌入直接服务聚类，且重构不能塌 | IDEC，而不是只有 KL 的 DEC | λ 曲线与噪声保持率均须实测 |
| 需要生成或软混合解释 | VaDE 或 GMM | 生成目标可能换不来更高的 ARI |
| 有可靠增强 | SimCLR 或 CC | 增益来自整条路线与网络/正则实现，不只来自对比损失 |
| 有与领域匹配的预训练模型 | 冻结特征 + K-means | 第二阶段聚类头须再提高 0.02 以上才值得 |
| 有外部文本，且文本和视觉类对齐 | TAC 一类方法 | 本综述不重训，仅作前沿边界，不作实测赢家 |

三个可证伪命题：（1）表征是否比聚类器更重要；（2）联合优化是否总是优于先表征再聚类；（3）预训练特征可用时，复杂聚类器是否仍值得额外成本。

## 2. 两套输出文件的严格分工（防测试标签泄漏）

| 文件 | 依赖测试标签？ | 实际使用的指标与口径 | 允许的用途 |
| --- | --- | --- | --- |
| `results/tables/selection.json`（E05） | **否**（仅读 `results/raw/E05_train/*.npz`） | 拟合训练子集上干净 vs. `σ=0.1` 扰动预测的 `macro_cluster_jaccard` 与非空簇检查（`clean_nonempty == noisy_nonempty == k`）；**当前 `max_predict_sec=None`，预测耗时未参与选择** | **仅用于坍缩与退化风险筛查**（例如淘汰遇微噪退化为单簇的像素 GMM），**不可称为“最佳方法推荐器”** |

| `results/tables/benchmark_cost_frontiers.csv` 与 `results/figures/fig_benchmark_pareto.png` | **是**（E01 测试集 ARI） | 端到端训练时间（DEC/IDEC 补回前置 AE 预训练）与测试集 ARI 的帕累托前沿 | **回顾性基准成本分析**，不属于无标签 E05 |

### 关于预测耗时与硬件口径（Issue #3）

- `choose_train_candidate()` 在当前 `scripts/analyze.py::training_selections()` 中以 `max_predict_sec=None` 调用，`selection.json` 显式记录 `"speed_used_in_selection": false`。
- 候选池中经典方法运行在 CPU，神经方法运行在 CUDA，不同设备的 `predict_sec` 仅作旁列诊断报告，不直接混排。若未来正式引入延迟约束，须先固定统一部署设备、批次大小与延迟预算阈值后再传入 `max_predict_sec`。

## 3. E05 负面诊断结论：稳定 ≠ 正确（Issue #5）

在三个数据集的从零 9 候选池上，仅最大化无标签扰动稳定性会系统性偏向对像素微扰迟钝的距离划分，从而出现**“稳定地分错”**的反例：

| 数据集 | E05 稳定性最高候选 | Macro Cluster Jaccard | 历史基准 ARI | 同基准更高结果 |
| --- | --- | ---: | ---: | --- |
| MNIST | PCA + K-means | 0.950 | 0.346 | DEC：0.669（VaDE：0.660） |
| Fashion-MNIST | 像素 K-means | 0.947 | 0.365 | DEC：0.435 |
| CIFAR-10 | 像素 K-means | 0.963 | 0.039 | DINOv2 + K-means：0.622（不在 E05 从零候选池） |

在六种正常工作的传统与深度方法上，训练稳定性与历史 ARI 的探索性 Spearman 秩相关在三数据集均为负（-0.49 / -0.60 / -0.54，每组 `n=6`，样本量极小，仅作探索性反例而非统计定论）。

## 4. 新无标签数据落地建议

1. **先做坍缩排雷**：使用 E05 扰动稳定性剔除空簇、单簇坍缩或严重偏斜的脆弱配置（如标准化像素对角 GMM）。
2. **明确候选范围**：若存在领域匹配的冻结视觉基础模型（DINOv2 / CLIP），应显式纳入候选评估，而非局限在从零小网络池中。
3. **语义确认需少量标注**：若要在全新领域确认分组是否符合业务语义，可人工标注少量验证样本（如 200 张），但这在方法学上属于**半监督 / 小样本验证方案**，不得与纯无标签选型混为一谈。
