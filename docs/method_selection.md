# 方法选型

下表是实验开始前的假设，不是结论。`results/tables/selection.json` 才会在测到数据后给出选择。那个文件由 `src/evaluation/selection.py` 生成，阈值来自协议，不手改。

| 条件 | 先考虑 | 要验证的说法 |
| --- | --- | --- |
| 维度低、类数已知、计算紧 | K-means 或 PCA + K-means | 非线性表征的 ARI 增益不超过 0.02 |
| 高维、没有外部模型 | AE，然后 K-means | 联合微调不一定更好 |
| 需要嵌入直接服务聚类，且重构不能塌 | IDEC，而不是只有 KL 的 DEC | λ 曲线和噪声保持率都要测到 |
| 需要生成或软混合解释 | VaDE 或 GMM | 生成目标可能换不来更高的 ARI |
| 有可靠增强 | SimCLR 或 CC | 增益来自整条路线，不只来自对比损失 |
| 有与领域匹配的预训练模型 | 冻结特征 + K-means | 第二阶段要再提高 0.02 才值得 |
| 有外部文本，且文本和视觉类对齐 | TAC 一类方法 | 这次不重训，只作为条件，不作为实测赢家 |

三个命题都允许被数据否定：表征是否比聚类器更重要；联合优化是否总是优于先表征再聚类；预训练特征可用时，复杂聚类是否还值那个成本。
