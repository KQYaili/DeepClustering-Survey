# 同一个分组任务，可以怎样学习

以服饰照片为例，表示模块把每张照片写成一串数，聚类模块把这些数分组。Zhou 等人用二者怎样相互影响来组织文献。图 1 给出下面四种交互关系，第 5 节详述方法。年份相近的方法可以采用不同交互，一套实际工作流也可以先预训练再联合更新。[综述图 1 与第 5 节](https://arxiv.org/pdf/2206.07579)

| 综述图 1 的用词 | 训练时发生什么 | 代表例子 |
| --- | --- | --- |
| Multi-stage（多阶段） | 先学描述图片的特征，再固定特征分组 | AE 或 SimCLR 提取特征后做 K-means |
| Iterative（交替） | 用当前特征聚类，再把这轮簇编号作为临时监督信号学习下一轮特征 | DeepCluster |
| Generative（生成） | 用潜在簇解释图像的生成过程，再从图像推断簇归属 | VaDE |
| Simultaneously（同时优化） | 同一个训练过程里，表征和聚类模块共同接受目标函数的更新 | DEC、IDEC；依靠双视图约束的 CC |

经典 K-means 和 GMM 提供固定坐标下的距离与概率基线。冻结 DINOv2 或 CLIP 后做 K-means 也采用分阶段工作流，但它们从课程数据之外获得表示。TAC 在图像分组时引入外部词汇。外部知识的来源是另一个问题，可以与上表的交互方式同时描述。

拿到新方法时，依次记下它使用的坐标（像素、线性投影、深度表示或外部表示）、更新方式（分阶段、交替或联合）、分配依据（距离、混合成分或网络输出）、监督信号（重构、伪标签、增强视图或外部语义）。例如 SimCLR + K-means 与 CC 都使用增强视图，但前者训练时只学特征，后者训练时已经输出簇分配。
