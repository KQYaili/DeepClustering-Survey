# 数学对象

K-means 在给定坐标上最小化

min Σ_i ||x_i − μ_{c_i}||²

深度聚类把坐标也变成可学习的：x 经过 f_θ 得到 z，再在 z 上分配簇。

DEC 用自由度为 1 的 Student-t 核做软分配。α = 1 时

q_ij ∝ (1 + ||z_i − μ_j||²)^(−1)

目标分布把 q 按簇频率归一化后再平方，p_ij ∝ q_ij² / f_j。训练最小化样本平均的 KL(p‖q)。p 在每个 epoch 开始时由当前全体训练嵌入算一次，不通过它反传。

IDEC 加上重构：

L = KL(p‖q) + λ · (1/B) Σ_i ||x_i − x̂_i||²

第二项是每张图所有像素的平方和，不是像素平均。λ = 0 时梯度不再更新解码器。

VaDE 的先验是对角高斯混合。推理网络给出 q(z|x)，簇责任由混合成分的后验算出。本仓库的重构项同样用每图平方误差，不用原论文的 Bernoulli 解码。因此 VaDE 的数字不能直接和 Jiang 等人表里的数字对比。

SimCLR 在两个增强视图的投影上做 NT-Xent，温度 0.5。K-means 用的是投影头之前的 128 维骨干。CC 另外把两个视图的簇分配矩阵按列做对比，实例温度 0.5，簇温度 1.0。MNIST 不做水平翻转。

选型用的不是一个标量分数。在测到的行上，帕累托比较最大化 ARI 和最小化训练时间。决策树的阈值是：预训练 K-means 要比从零训练的最好深度方法高 0.05 才优先；同一特征上的第二阶段还要再高 0.02 才值得训练；IDEC 要比 AE+K-means 高 0.02，并且噪声 0.3 时的 ARI 至少保留干净 ARI 的 90%。缺任何一项测量，对应规则不生效。
